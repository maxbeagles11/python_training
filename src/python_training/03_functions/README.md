# 03_functions
`Functions` are fundamental for designing **scalable** and **modular** code. They allow us to compartmentalize our code which has the following benefits:

1. **Improves readability** – Easier to follow and understand.
2. **Encourages reusability** – Write once, use many times.
3. **Reduces repetition** – Don't repeat yourself.
4. **Enables algorithms and abstraction** – You can isolate logic cleanly.

This folder will cover the following concepts:
1. Defining functions.
> How to properly define a function.
2. Function calls.
> How to use a function.
3. Parameters and arguments.
> Passing data into your functions.
4. Return values.
> The output of a function.
5. Default arguments.
> Default inputs for functions.
6. Keyword vs positional arguments.
> Describing how arguments are organized.
7. Docstrings.
> As we've covered before, we **need** to use docstrings to explain what functions do.
8. Scope.
> Understanding global vs local variables.
